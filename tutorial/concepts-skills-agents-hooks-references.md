# Skills、agents、hooks、references

**Skill**定义一个可复用任务：什么时候用、读什么、怎样判断与验证。它是提示内容，不能保证每一步自动执行。Claude从`.claude/skills/`使用；GPT版按其自己的发现约定。

**Agent**把一个具体子任务交给独立角色。适合并行文献/数据工作或重要结果的独立审查。主线程仍要核对它的证据；多个agent同意不等于事实成立。局部改句子不需要自动派全套。

**Hook**是在已配置事件发生时运行的代码。当前保护仅覆盖声明的工具调用，lint是提示；压缩hook保存已有交接线索，不替代模型主动更新PROJECT_BRIEF，不执行`/checkpoint`，更不能创造用户批准。`post-merge.sh`作为保留工具文件并不意味着已安装Git hook。

**Reference**放只在某类任务需要的细节，如写作体例、特定语言代码或方法条件。入口给明确路径和读取时机，避免每次开局装入整本手册。

**状态材料**不是这四种配置的替代品。PROJECT_BRIEF解释当前问题和认识，EVIDENCE_LEDGER追溯主张，DECISIONS记录研究者选择。模板为尚未发生的研究留占位，不能将样例变成事实。
