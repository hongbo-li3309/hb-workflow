# 为什么用这个工作流

AI可以减少检索、数据整理、代码修改和文字编辑的重复劳动。研究者仍要判断问题是否重要、机制是否合理，以及证据究竟能说明什么。因此当前设计让AI提出判断，也要求它呈现理由、反证和替代路线。

一页PROJECT_BRIEF保留主线，证据账记录重要主张，决定记录区分建议和已确认选择。探索可以大胆，但结果必须允许改变最初的故事。技能和agent为具体任务服务，不用数量或分数代表研究质量。

读不懂的方法值得拆开学习。AI应先讲为什么需要它，用toy model建立直觉，再解释假设、推导和可观测含义；不会因为你是博士生或暂不熟悉某个领域就降低探索范围。

Claude版和GPT/Codex版执行相同研究原则，工具机制不同。独立目录让你能分开选择和比较，不能据其中一版能跑就断言另一版也通过。
