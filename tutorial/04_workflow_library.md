# 技能按问题选择

完整入口见 [快速参考](../.claude/WORKFLOW_QUICK_REF.md)。无需按固定顺序运行全部命令。

- 已有一个模糊问题：`/discover interview` 或直接讨论。信息充分就进入机制与证据比较。
- 想创新：`/discover brainstorm`。要求说明经济机制、已有证据和最小检验；跨领域方向有价值时保留。
- 已有文献：`/discover frontier` 更新与去重，不能把旧列表叫最新。
- 有结果但主线散：`/strategize focus`，解释哪些结果改变核心判断，哪些暂放附录/备选。
- 想用陌生方法：`/learn`。可以要求直觉、推导、代码例子或阅读路线。
- 有稿件：`/write`、`/review`、`/revise`，指定主稿与任务；微调不必全套审稿。

skill是任务指令，不是已经执行的事实。工具缺失就明确NOT_RUN，继续不依赖它的工作。
