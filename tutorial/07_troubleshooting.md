# 出问题时检查什么

| 现象 | 下一步 |
|---|---|
| 找不到skill | 确认进入正确版本/项目目录、SKILL.md的name/description；重新加载客户端并看实际发现列表 |
| Stata MCP不可用 | 核对连接器工具与许可；有可用本地batch且任务允许时使用，否则标NOT_RUN |
| hook没有反馈 | 检查settings中的事件、stdin JSON和退出码；运行hooks测试，不只检查shell语法 |
| 恢复出错任务 | 核对project_root、session_id、活动指针和PROJECT_BRIEF；不凭最新修改时间选计划 |
| 有旧PDF但本次编译失败 | 以本次退出状态为准，旧产物不能证明成功；查看编译日志 |
| AI反复索要同一步批准 | 指出已批准的范围，继续常规工作；核心研究判断与外部操作另按实际授权处理 |
| 项目越来越散 | `/strategize focus`，让每个结果对应一个问题，保留反证，选最有判别力的下一步 |
| 生成器说目标已存在 | 保留目标并检查内容，换新路径或走已有项目迁移，不自动删除 |

具体权限错误应说明被拒绝的动作和来源，不能通过换通道绕过限制。工具无法执行与研究方法不成立是不同问题，要分别报告。
