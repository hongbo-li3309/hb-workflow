# 按读者与体例写作

本文件指导表达选择，不替代项目证据。先读当前任务对应体例，再按需要读研究类型和编辑部分。主稿与修订版本遵循 `.claude/rules/revision.md`；领域样本见 `writing-exemplars.md`，个人明确偏好见 `personal-style-guide.md`。

## 开始前的简短判断

从用户任务、主稿和 `research/PROJECT_BRIEF.md` 判断：谁读、读后要理解或决定什么、语言与体例、研究类型、当前章节的作用。已有上下文足够时直接做。缺少结论可以起草逻辑和占位；不能补出结果。只在无法判定主稿或会改变研究含义时提出具体问题。

选择顺序：用户本次要求 → 已确认个人偏好 → 本次读者和体例 → 最贴近的领域样本。准确性贯穿各层；任何风格选择都不能加强证据。

## 英文学术论文

让读者先知道经济问题为何尚未解决，再知道本文新增什么判断。具体制度事实、理论冲突、测量缺口或难以解释的模式都可以开篇，不要求每篇从宏大趋势写起。

- 引言把问题、机制、研究对象、主要贡献连起来。贡献用与最接近论文的实质差别说明，避免列出“首次使用数据、首次使用方法”就结束。
- 主语尽量明确，动词说明研究动作或经济行为。保留表达不确定性的必要限定；`is associated with`、`suggests`、`under the model` 有不同含义。
- 长句适合解释条件、比较和因果链，短句适合给出关键判断。让长度由论证决定，不规定词数分布、被动语态占比或某词出现次数。
- 一个段落有可概括的中心任务，可以同时包含结果、证据和限定。段落之间推动判断，不重复小结，不强制每段以数字或固定句式开头。
- 图表的主要发现要进入文字；叙述回答经济大小和机制，避免逐列朗读。理论文章应明确命题改变了哪种经济判断；没有估计结果也可有完整贡献。

## 中文学术论文

用中文组织推理，避免把英文句法逐句搬过来。制度背景有解释功能时展开；背景本身不是贡献。

- 尽早落到明确问题、作用对象与机制。少用连续名词修饰、“基于……视角下”的层叠结构和没有信息的“具有重要意义”。
- 句子先交代行为主体、制度约束或观察对象，再交代变化及解释。上下文清楚时可省主语，跨主体时主动补出，避免“其”“这一”指代漂移。
- 术语首次出现时给出准确中文，必要时保留英文对应；同一概念不为了避免重复而随意换词。`劳动需求`、`就业`、`招聘`、`岗位发布`不是可互换的词。
- 用“因此”“但”“同时”须有真实逻辑关系。条件推导、经验关联、机制解释分别表达；“表明”不能承担从相关到因果的跳跃。
- 根据目标期刊和贴近主题的中文原文调整文献对话、标题和段落节奏。没有中文样本时采用本节的暂定基线，不能声称英文 exemplar 已验证中文期刊风格。

## 中文政策报告

先明确读者掌握什么政策工具、面对什么选择，再决定是否先给建议、核心发现或问题诊断。正文围绕决策组织；技术过程放入方法框或附录，但保留足以判断证据可靠性的说明。

- 分清政策目标、可改变的机制、工具与约束。建议写清实施主体、对象、动作、条件和评价依据；不要凭空添加财政成本、实施能力或法律权限。
- 比较有意义的政策选项，包括维持现状或小范围试点。讨论受益者、成本承担者、执行激励及潜在替代行为。
- 单个企业、短期或局部效应不能直接写成全国就业或福利结论。建议强度随证据变化；证据有限时说明哪个试点或数据最能改善判断。
- 语言简明而有分析，不以口号、整齐排比、“全面加强”或行政术语代替具体行动。委托机构有格式要求时遵循其真实要求。

## 英文政策报告

围绕具体受众的 decision problem 组织：所需判断、可用证据、政策选项和取舍、实施条件。Executive summary 应能独立读懂，不压缩复制论文摘要。

- 说明政策要改变谁的行为、通过什么激励、预期影响哪些结果。把技术名词翻译为读者可用的含义，保留必要的估计对象和适用范围。
- 用有主体的行动建议；区分 observed evidence、model-based scenario 和 recommendation。不要把反事实模拟写成实际发生的事实。
- 短句用于结论与行动，较长句用于重要条件和权衡；不要为“简洁”删除不确定性、分配后果和执行风险。
- 需要官方政策、法律或预算事实时核验当期一手来源。本文体例规则不是对任何机构的正式行文规定。

## 研究类型决定必要内容

| 研究类型 | 读者需要掌握的关键链条 |
|---|---|
| 因果实证 | 经济问题 → estimand → 处理与比较来源 → 识别假设及威胁 → 估计与不确定性 → 可解释范围 |
| 描述／测量 | 定义和数据生成 → 覆盖及误差 → 事实与不确定性 → 与既有测量的区别 → 事实能排除什么 |
| 结构／量化模型 | 环境、选择、约束与均衡 → 参数来源 → 识别或校准依据 → 拟合与验证 → 反事实及敏感性 |
| 纯理论／方法 | 经济问题 → 对象与假设 → 命题或识别结果 → 关键逻辑和证明 → 边界与反例 → 经济含义 |
| 理论与实证结合 | 机制 → 判别性预测 → 可观察对象和设计 → 证据 → 未被验证的模型部分 |

这是覆盖提示，不是固定章节模板。校准、估计、预测和因果解释分别命名。校准有其合理用途，不能只因为参数未经本样本估计就认定研究较弱；反事实可信度需要针对其参数依据和外推假设判断。

## 编辑不能改变的含义

重要主张核对 `research/EVIDENCE_LEDGER.md` 所链接的具体输出或原文：样本与时间、基准组、单位、系数与区间、处理定义、识别条件、证据版本。正文数字可合理取整，但必须与输出相符。若稿件与输出冲突，标出冲突及来源，不用润色悄悄消除。

- 就业率由 40% 升至 42%，是增加 2 个百分点或相对增加 5%；不能写成“增加 2%”。这是单位示例，不是项目结果。
- 以自然对数工资为因变量、二元变量系数为 0.04 时，在相应模型解释下约为 4% 的比例差异；精确转换为 `100 × (exp(0.04) − 1)`。因果措辞仍取决于设计，工资变化不用“百分点”。
- “处理前系数未显著偏离零”只描述检测结果，不能改成“证实平行趋势”。需要考虑区间、检验能力和可能的偏离。
- “高暴露企业发布的岗位较少”不能在主动语态润色后变成“AI 减少了岗位”。生产率提高也不直接意味着减少雇员、提高利润或增加社会福利。
- 机制异质性可以与解释一致，但未必排除竞争机制；不要把它升级为独立识别。模型给定条件下的命题须保留条件。

清理 AI 味时先删空泛主张和无效重复，再调语序、段落与节奏。词语不是证据：术语中合理的 `robust`、必要的排比和被动句可以保留。中英改写重新组织表达，但核对同一份事实清单。

## 写作交付与学习

给出可审阅稿件、与主稿的差异及必要的待核事项。对重要改动，用少量代表性例子解释“这个句子为什么更准确”“这个段落为何放在这里”，帮助 Hongbo 逐步掌握写作判断；无需给每句附教程。

大幅重构先说明现有主线的障碍和建议组织方式，在已授权范围内提供具体改稿。需要改变问题、estimand 或主结论的提议单独提出，不能藏在语言修改中。简单润色不强加完整 worker–critic 流程。
