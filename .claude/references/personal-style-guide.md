# Hongbo 的写作偏好

本文件可由 Hongbo 直接修改。最新明确指令优先；观察不能自动升级为个人偏好。状态截至 2026-09-13：已有明确要求，尚未用 Hongbo 指定的满意样稿验证个人声音。

## 已确认的偏好

依据：Hongbo 对本轮 workflow 重构的说明及项目指令。

- 默认中文交流，保留有必要的英文术语。中英论文、政策报告分别写，不逐句套用同一种规范。
- 清楚、简明、逻辑连贯，长短句结合，避免空话、机械过渡和碎片化段落。
- 随经济问题和领域选择真实优质样本，学习准确用词、句法和论证；保持内容有特点，不千篇一律。
- 先解释研究问题和经济机制，再讲假设、数据和识别。方法难度不是回避探索的理由，应支持学习。
- 以用户指定主稿为准，保留其格式；大改另存新版本并保留可审阅差异。个人或项目事实以最新明确说明为准。

上述是用户要求，不是从语料推断出的句长、词汇或作者习惯。

## 暂定的领域参考

按 `writing-guide.md` 选择体例，按 `writing-exemplars.md` 选择贴近任务的样本。尚无 Hongbo 确认的专用术语偏好、满意样稿或被明确否决的句式记录。不要补造这些内容，也不为填模板发起访谈。

## 如何更新

`/write style-guide [样稿或目录]` 读取用户指定材料和明确修订。单篇也可用于局部观察，但说明可迁移范围；不因少于两篇而停止。比较原句与用户改句比统计词频更有信息。

每项新观察简记：材料／版本／读取段落 → 原句与修改的必要片段 → 可能偏好 → 适用语言及体例 → 状态。状态为“候选观察”或“用户已确认”，明确否决的旧观察标记已替代。保留已有确认内容，不因一次抽样覆盖整份文件。

可以在当前稿件中尝试有依据的局部改法并供用户审阅；只有用户确认后才写成跨项目偏好。不要根据模型自己的旧稿反推“用户的声音”。不设句长、被动句或标点配额；用户认可的表达也不能改变证据强度。
