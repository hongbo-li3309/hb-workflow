# 平台能力与实际边界

核验日期：2026-09-13；本机 CLI：0.154.0。以下区分配置支持、本版实现与实际运行证据，不从版本号推断所有功能已集成测试。

## 原生入口

Codex 从项目层级读取 `AGENTS.md`，也会继承用户级指令；进入嵌套目录并不取消祖先层的作用。为了分开使用，把本版复制到独立目录或通过初始化器创建独立研究项目，再从该项目根启动。不要把根目录不同当作已经屏蔽全局指令。[官方 AGENTS.md 说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md)

本地技能位于 `.agents/skills/<name>/SKILL.md`，保留 name／description 与任务指令。在 Codex 可从技能列表或 `$` 选择，也可依任务自动匹配；本版没有定义同名自定义 slash 命令。单独复制某个 SKILL.md 会丢失其引用，使用时复制整个包。[官方 skills 说明](https://learn.chatgpt.com/docs/build-skills)

`.codex/config.toml` 不设置固定模型、权限、并发或 MCP；这些继承用户环境。项目级配置的加载依赖信任状态和客户端配置，用户／组织层也可影响行为。本版不写全局文件、不预先信任任意路径。[官方配置说明](https://learn.chatgpt.com/docs/config-file/config-basic)

20 个角色使用 `.codex/agents/*.toml`，按官方支持的独立文件格式提供 name、description、developer_instructions；审查角色另设 read-only 默认。角色不固定模型／推理强度。运行时权限覆盖及外部工具仍需按真实能力判断，不能把角色文件当作完整权限隔离。[官方 subagents 说明](https://learn.chatgpt.com/docs/agent-configuration/subagents)

## 本版的能力契约

| 能力 | 本版实现 | 无法使用时 |
|---|---|---|
| 任务技能 | 本目录 12 个原生 skills 和自然语言提示 | 明确读取所需技能文件，按同一契约串行工作 |
| 专业角色 | 20 个 TOML 配置；只有实际启动才称子 agent | 通用子 agent 可接收角色指令；全无工具则串行自查，注明独立性限制 |
| 文件／shell | 使用当前客户端提供的工具和权限 | 交付未执行脚本／可审阅修改，记录 NOT_RUN |
| 文献检索 | 运行时选择实际可用的检索／网页工具，一手来源优先 | 整理已有材料；当期前沿、新颖性和未读原文仍为未核验 |
| Stata | 运行时发现 MCP；已配置且有许可的 batch 可替代 | 保存 do 文件、给运行入口，不能称回归已完成 |
| 编译／视觉检查 | 实际 latexmk／Quarto 与可用渲染查看工具 | 分别报告编译或视觉检查 NOT_RUN |
| checkpoint | 显式技能和 Python 脚本；本地 task key，核对根目录与可选会话 ID | 公共 brief 仍可读，不以未知状态恢复授权 |
| lint／运行记录 | 显式调用 lint_research.py／run_check.py | 给缺失工具或输入及具体下一步 |
| 文件保护 | 已确认授权、另存主稿、原始数据规则、客户端实际权限 | 无自动跨工具拦截承诺，编辑前核对范围 |
| 外部记忆／笔记 | 仅在已有明确授权与可用工具下同步 | 项目内 MEMORY／research 保持完整；不假报已保存到外部 |

本版**没有安装自动 hooks**，不声明在编辑、压缩、退出或 Git 操作时自动执行。Codex 可能具有其他 hooks 能力，但本次选择以明确调用的工作流实现交接和检查，未来适配需另核验事件及权限。客户端自带 resume 可以恢复对话，仍须核对本项目状态；本地 checkpoint 文件不能复原模型内部上下文。

## 验证的解释

TOML/YAML 结构校验说明配置文件可解析；隔离初始化说明复制包不依赖父目录。脚本测试检查失败传播、证据时效和任务隔离。它们不证明在线模型会在所有提示下按预期选择角色，也不代替真实 Stata、论文编译或经济学评议。

实际可用工具列表以当前会话为准。普通网页聊天没有本地工具时，可采用这里的研究和写作规则，但不能声称已获得本地文件系统、自定义角色或自动化运行能力。
